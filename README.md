# Calculator Using HTML, CSS, and JavaScript

A simple calculator web application built with HTML, CSS, and JavaScript. This project demonstrates the basic functionality of a calculator, allowing users to perform arithmetic operations in a clean and responsive interface.

## Features

- Addition, subtraction, multiplication, and division
- Clear and delete buttons
- Responsive design for mobile and desktop
- User-friendly interface

## Demo

You can view a live demo by opening the `index.html` file in your browser.

## Getting Started

### Prerequisites

No special prerequisites are required—just a modern web browser.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/agastya3636/calculator_using_htmlcssjs.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd calculator_using_htmlcssjs
   ```

3. **Open the app:**
   - Double-click `index.html`, or
   - Run a local HTTP server and navigate to `http://localhost:PORT/index.html` in your browser.

## Usage

- Enter numbers and select operations to calculate results.
- Use the clear button to reset the display.
- Use the delete button to remove the last digit.
